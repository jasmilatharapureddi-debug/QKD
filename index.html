The BB84 Protocol Architecture

Physical layer quantum mechanics guarantees unconditionally secure key exchange that Shor's algorithm cannot compromise.

⚛ Live Quantum Fiber Channel Transmission
Alice: Random Bit $a_k \in \{0,1\}$, Basis $\{Z, X\}$ Eve: Intercept-Resend Active Bob: Independent Basis $\{Z, X\}$, Single Photon Detector
01 🎲
State Preparation
Alice samples random bit $a_k \in \{0,1\}$ and basis $\{Z, X\}$. She applies Pauli-X (if bit=1) and Hadamard gate $H$ (if X basis) to construct $|0\rangle, |1\rangle, |+\rangle, |-\rangle$.
02 📡
Channel & Eavesdropping
Qubits travel through optical fiber with attenuation $\alpha \approx 0.2\text{ dB/km}$. Eve attempts either Intercept-Resend or CNOT probe entanglement.
03 🔭
Bob's Measurement
Bob independently selects basis $\{Z, X\}$ for each arriving photon and performs projective measurement, recording the classical raw bit.
04 ⚖
Public Sifting
Alice and Bob announce bases publicly (no bits revealed). Qubits where bases mismatched are discarded, yielding $\approx 50\%$ sifted key length.
05 🔍
QBER Parameter Estimation
A sacrificed sample of sifted bits is compared. If $\text{QBER} > 11\%$ (Shor-Preskill abort threshold), transmission aborts immediately due to adversary presence.
06 🛡
Error Correction & PA
Cascade/Winnow parity checks rectify channel errors. Universal Toeplitz hashing compresses the key, shrinking Eve's mutual information to zero.

Quantum Adversary Modeling

Eavesdropping Attacks & Information-Theoretic Bounds

Comparative analysis of Intercept-Resend vs Entanglement-based beam-splitter attacks.

Intercept-Resend Analytical Model

Eve intercepts every photon in transit, measuring it in a randomly chosen basis $\{Z, X\}$. Because quantum states cannot be cloned (No-Cloning Theorem), Eve must re-prepare a photon to forward to Bob.

P(Basis Mismatch) = 1/2
P(Bob Error | Mismatch) = 1/2
Expected QBER = 1/2 × 1/2 = 25.0%

Since $25\% \gg 11\%$ (the Shor-Preskill security limit), a full intercept-resend attack is guaranteed to be detected and rejected by Alice and Bob.

Entanglement Probe / Beam-Splitter Attack

Rather than projecting the qubit immediately, Eve couples her ancilla probe $|0\rangle_E$ via a CNOT gate:

(\alpha|0\rangle + \beta|1\rangle) \otimes |0\rangle_E \xrightarrow{\text{CNOT}} \alpha|00\rangle + \beta|11\rangle
I(A;E) \le \chi(\rho_E) \quad \text{(Holevo Bound)}

Eve gains partial information without introducing a full 25% error. However, any non-zero information extraction inevitably introduces phase/bit disturbance.

Shor-Preskill Asymptotic Key Rate Formula

The asymptotic distillable secret key fraction $R$ per sifted qubit is lower-bounded by:

R \ge 1 - 2H_2(\text{QBER})
H_2(p) = -p\log_2(p) - (1-p)\log_2(1-p)
R = 0 \iff H_2(\text{QBER}) = 0.5 \iff \mathbf{\text{QBER} \approx 11.04\%}

The factor of $2$ accounts for $H_2(\text{QBER})$ leaked during error correction and $H_2(\text{QBER})$ sacrificed for privacy amplification against phase errors.

Reconciling classical discrepancies and distilling a purely random, unconditionally secret key.

Cascade Protocol Simulation

Alice and Bob split their sifted strings into blocks of size $k_1 \approx 0.73/\text{QBER}$. They exchange block parities. When parities disagree, binary search bisection pinpoints the single flipped bit.

[Pass 1: Block Parity Bisection]
Block 1 (Bits 0..7): Alice Parity=1, Bob Parity=0 → DISCREPANCY DETECTED
Bisection: Split into Bits 0..3 vs 4..7 → Discrepancy in Bits 4..7
Bit #6 corrected: $0 \to 1$. Parity re-matched.

💡 Hackathon Architectural Recommendation: The Hybrid QKD+PQC Model

Neither QKD nor PQC represents an isolated silver bullet. While ML-KEM provides software agility and internet-scale key encapsulation, its security relies on unproven computational complexity assumptions. Conversely, BB84 QKD provides unconditional, physics-based forward secrecy but faces physical distance attenuation and dark-fiber hardware limits. The optimal national cyber-defense strategy combines ML-KEM-768 with BB84 QKD key-mixing ($K = \text{KDF}(K_{\text{PQC}} \oplus K_{\text{QKD}})$), requiring an adversary to break both the physical channel and lattice hardness simultaneously.

bb84_qiskit_simulation.py 
import numpy as np
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister
from qiskit_aer import AerSimulator

def binary_entropy(p: float) -> float:
    """Calculates binary Shannon entropy H2(p)."""
    if p <= 0.0 or p >= 1.0:
        return 0.0
    return -p * np.log2(p) - (1.0 - p) * np.log2(1.0 - p)

def run_bb84_simulation(num_qubits: int = 100, eve_strategy: str = "intercept_resend"):
    backend = AerSimulator()
    alice_bits = np.random.randint(0, 2, size=num_qubits)
    alice_bases = np.random.choice(['Z', 'X'], size=num_qubits)
    bob_bases = np.random.choice(['Z', 'X'], size=num_qubits)
    bob_bits = []

    for i in range(num_qubits):
        qr = QuantumRegister(2, 'q')
        cr = ClassicalRegister(2, 'c')
        qc = QuantumCircuit(qr, cr)

        # Alice prepares qubit
        if alice_bits[i] == 1:
            qc.x(qr[0])
        if alice_bases[i] == 'X':
            qc.h(qr[0])

        # Eve attack
        if eve_strategy == "intercept_resend":
            eve_basis = np.random.choice(['Z', 'X'])
            if eve_basis == 'X':
                qc.h(qr[0])
            qc.measure(qr[0], cr[1])
            if eve_basis == 'X':
                qc.h(qr[0])
        elif eve_strategy == "cnot_probe":
            qc.cx(qr[0], qr[1])

        # Bob measures
        if bob_bases[i] == 'X':
            qc.h(qr[0])
        qc.measure(qr[0], cr[0])

        result = backend.run(qc, shots=1, memory=True).result()
        measured = int(result.get_memory()[0][-1])
        bob_bits.append(measured)

    # Sifting & Parameter Estimation
    sifted = np.where(alice_bases == bob_bases)[0]
    sample_size = len(sifted) // 4
    errors = np.sum(alice_bits[sifted[:sample_size]] != np.array(bob_bits)[sifted[:sample_size]])
    qber = errors / sample_size if sample_size > 0 else 0
    key_rate = max(0.0, 1.0 - 2.0 * binary_entropy(qber))

    print(f"Sifted Bits: {len(sifted)} | QBER: {qber*100:.2f}% | Secret Key Rate: {key_rate:.3f}")
    return qber, key_rate

if __name__ == "__main__":
    run_bb84_simulation(num_qubits=200, eve_strategy="intercept_resend")
